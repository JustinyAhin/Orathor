## Important for some existing users

If Accessibility appears enabled but Orathor still copies text to the clipboard, macOS may still trust an older development-signed build.

1. Quit Orathor.
2. Run `tccutil reset Accessibility segbedji.Orathor` in Terminal.
3. Reopen Orathor and enable it again in System Settings → Privacy & Security → Accessibility.
4. Quit and reopen Orathor once more after enabling it.

This is a one-time migration for affected existing users. New installations are unaffected.

Support

Orathor requires macOS 26.2 or later. It lives in the menu bar and uses a configurable hold-to-dictate shortcut.

Dictation does not start

Open Orathor Settings and check Microphone, Speech Recognition, and Accessibility. Accessibility is required to insert text into the app under your cursor. If a permission looks stuck, open the matching macOS System Settings page from Orathor and grant it again.

Cloud engines do not connect

Deepgram and OpenAI are optional bring-your-own-key engines. Confirm the selected provider’s API key is valid and that the Mac is online. Switch back to Apple for on-device dictation.

Send a useful report

In Settings → Diagnostics, choose “Copy Diagnostic Log.” Review it, remove anything you do not want to share, then include it with a GitHub support issue. Never post an API key, license key, private transcript, or recording.

Setapp membership

If the Setapp edition reports an inactive membership, open the Setapp desktop app, sign in, and verify your subscription. Setapp handles billing and subscription support.

Updates and release history

Setapp updates the Setapp edition. The direct edition checks for updates through Sparkle. See the Orathor changelog for release details.
